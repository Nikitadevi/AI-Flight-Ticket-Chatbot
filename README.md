# AI-Flight-Ticket-Chatbot

SkyBot is a sleek and interactive AI-powered flight price assistant built using HTML, CSS, and vanilla JavaScript. It simulates a travel chatbot that helps users check popular flight routes, get travel tips, and discover the cheapest days to fly — all with voice-enabled responses and a modern UI.

 # Features
1 Conversational Interface with dynamic bot replies

2 Quick Suggestions for popular Indian flight routes

3 Speech Synthesis for spoken bot responses

4 Cheapest Travel Day Finder by state and month

5 Travel Tips for safe and smart journeys

6 Modern UI with background image, gradient overlay, and message bubbles

# Tech Stack
Frontend: HTML5, CSS3, JavaScript (Vanilla)

Design: Responsive layout, button-based suggestions, chatbot-style interface

APIs: Web Speech API for text-to-speech

# How to Use
Clone or download the repo.

Open the index.html file in any modern browser.

Type or click a quick suggestion to interact with SkyBot.

Enjoy real-time voice responses and travel assistance!
